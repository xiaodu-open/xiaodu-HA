# XiaoDu 小度智能家居集成（Home Assistant 自定义集成）

把百度小度（DuerOS）账号下的智能家居设备接入 Home Assistant，支持状态同步与设备控制。

> 授权经由分享者部署的**中转服务**完成：集成里不含任何 OAuth 凭据（连 `client_id` 都没有），
> 你也不需要修改 HA 地址或申请回调白名单，
> 点「添加集成」→ 跳转到百度输入自己的账号密码 → 同意授权即可。

---

## 一、它能做什么

自动拉取小度账号下已绑定的设备，每 10 秒刷新一次状态，并按设备类型生成 HA 实体：

| 小度设备类型　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　| HA 平台　　　　　　　 | 支持的操作　　　　　　　　　　　　　　　　　　　　　　　　　|
| -------------------------------------------------------------------------| -----------------------| -------------------------------------------------------------|
| 灯、筒灯、射灯、氛围灯、吸顶灯、落地灯、调光面板、彩灯　　　　　　　　　| `light`　　　　　　　 | 开/关、亮度、色温（2700–6500K）　　　　　　　　　　　　　　 |
| 窗帘、卷帘、百叶、开窗器　　　　　　　　　　　　　　　　　　　　　　　　| `cover`　　　　　　　 | 开/关、开合比例、百叶角度　　　　　　　　　　　　　　　　　 |
| 空调（含柜机、面板、无状态机型）　　　　　　　　　　　　　　　　　　　　| `climate`　　　　　　 | 开/关、模式（制冷/制热/除湿/送风/自动）、目标温度、三档风速 |
| 地暖、热水器、取暖器、浴霸　　　　　　　　　　　　　　　　　　　　　　　| `climate` 或 `switch` | 能调温的归 `climate`（开/关 + 温度），否则归 `switch`　　　 |
| 风扇、塔扇　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　| `fan`　　　　　　　　 | 开/关、三档风速　　　　　　　　　　　　　　　　　　　　　　 |
| 开关、插座、音箱、净化器、加湿器、晾衣架等　　　　　　　　　　　　　　　| `switch`　　　　　　　| 开/关　　　　　　　　　　　　　　　　　　　　　　　　　　　 |
| 温湿度计、体脂秤、空气检测（PM2.5/PM10/甲醛/TVOC/气压）、电量、设备状态 | `sensor`　　　　　　　| 只读　　　　　　　　　　　　　　　　　　　　　　　　　　　　|
| 小度 App 里的场景　　　　　　　　　　　　　　　　　　　　　　　　　　　 | `scene`　　　　　　　 | 可在自动化里直接触发（每 5 分钟同步一次）　　　　　　　　　 |

其它特性：

- **按需暴露能力**：只生成设备自己声明支持的操作，点不动的按钮不会出现。
- **多路开关聚合**：多键开关面板的每一路不再是独立设备，而是同一台设备
  下的多个实体，友好名形如「小度智能开关 C1 左键」，一张卡片操作全部按键；
  区域跟随面板设备，不必再逐键设置。
- **控制即时反馈**：下发后 UI 立刻显示目标状态，并在 2/5/10/13 秒递进补刷云端真实状态。
- **重名保护**：小度云端只能按「设备名 + 房间 + 楼层」定位设备，完全重名时集成直接报错，
  不会控错设备。
- **在线状态同步**：设备离线时实体显示为 unavailable。
- **诊断下载**：集成页面可下载诊断信息，只含聚合统计，不含 token 与设备名。

### 已知能力边界

小度云端开放给第三方的控制指令是一份固定清单，下列能力即使设备本身支持，也没有可用的
下发通道，本集成无法实现：

彩灯颜色（RGB）、音箱音量与静音、音箱播放控制、门锁上锁与解锁、扫地机吸力与水量、
电视频道与红外按键、湿度设定、窗帘暂停。

因此音箱只作为 `switch` 实体提供开/关，没有播放控制。

## 二、前提条件

1. 一个能运行的 Home Assistant（Docker 或其它方式均可）。
2. 一个**百度/小度账号**，并已在「小度」App 里绑定好设备。
3. 分享者的中转服务处于运行状态。集成里需要你关心的常量只有一个——
   `const.py` 的 `AUTH_PROXY_BASE`，填分享者给的中转服务地址。

---

## 三、安装

1. 把 `xiaodu` 整个文件夹放到 HA 配置目录下：
   ```
   config/custom_components/xiaodu/
   ```
2. **重启 Home Assistant**（自定义集成的代码只在启动时加载）。

### 品牌图标

`brand/` 目录下是集成图标素材（尺寸已符合官方要求）：

| 文件　　　　　| 尺寸　　 | 用途　　　　|
| ---------------| ----------| -------------|
| `icon.png`　　| 256×256　| 集成图标　　|
| `icon@2x.png` | 512×512　| 高分屏图标　|
| `logo.png`　　| 794×256　| 集成 logo　 |
| `logo@2x.png` | 1589×512 | 高分屏 logo |

---

## 四、添加集成并授权

1. 设置 → 设备与服务 → 右下角 **+ 添加集成**
2. 搜索 **XiaoDu** 并选择
3. 页面会**自动跳转到百度授权页**，用你的小度账号登录并点「同意/授权」
4. 授权成功后自动跳回 HA，完成配置，设备随即出现

## 五、常见问题

**1. 搜不到 XiaoDu 集成**
- 确认文件夹路径是 `config/custom_components/xiaodu/`（里面有 `manifest.json`）
- 重启 HA 后浏览器强刷：`Ctrl+Shift+R`（Mac 用 `Cmd+Shift+R`）

**2. 设置失败，日志出现「无法连接中转服务」**
- 中转服务可能没运行或域名/证书有问题，联系分享者。HA 会自动重试，服务恢复后无需手动操作

**3. 提示「授权已失效，请重新授权」**
- refresh_token 过期或被吊销，按通知重新授权一次

**4. 日志提示登录态失效**
- 删除该集成条目后重新添加授权

**5. 看不到某些设备**
- 只有类型能被识别的设备会生成实体（灯/窗帘/空调/风扇/开关/传感器），未识别类型会跳过
- 纯输入类设备（无线按键、场景面板、旋钮）不生成实体：它们只上报事件，没有可控状态
- 多键面板本身不生成实体，控制入口是挂在它下面的各路实体

**6. 提示「小度设备名称与位置重复，无法准确定位」**
- 小度只能按「设备名 + 房间 + 楼层」定位设备，完全重名时无法判断该控哪个，
  请在小度 App 里把其中一个改名

**7. 有些设备看着像一块面板，但在 HA 里还是分开的**
- 聚合的依据是云端返回的父子关系。有一类设备在云端就是**平级的顶层设备**，既没有父子
  关系，也没有代表面板本身的记录——连面板名称都拿不到。对这类设备做聚合只能凭空造一个
  以序列号命名的设备，比分开显示更难用，因此不做。

## 六、使用与限制说明

- **共用配额**：所有使用者共用分享者的百度应用配额，请勿滥用。密钥由分享者在中转服务侧
  集中管理，轮换时你无需更新集成。
- **控制范围**：受设备自身声明的能力与云端开放指令清单双重限制，见第一节「已知能力边界」。
- **隐私**：授权后 token 保存在你自己 HA 的 `.storage` 里（明文，属 HA 常规做法）；
  中转服务只做 token 交换的转发，不保存 token。
